# 更新记录

## 仓库整理（2026-10-26）

- 独立目录与建议 GitHub 仓库名：`azeroth-survivors-trainer`。
- 以现有 v3.3.1 源码为基线，只收录 26 个运行、测试与构建文件；原目录保留。
- 统一使用 `README.md` 作为使用手册，界面“打开使用说明”指向该文件。
- `AGENTS.md` 记录全部功能实现、版本布局、保存事务与维护规则。
- 增加 Git 忽略规则和上传说明，隔离游戏文件、个人存档、备份、运行日志与构建产物。
- 未安装相邻游戏时，只读二进制兼容性测试明确跳过；有文件但版本错误仍失败。
- `source-baseline.json` 记录整理前 26 个文件的 SHA256，仅用于来源比对。

此次整理沿用功能版本 v3.3.1，没有扩展支持的游戏版本，也没有更改补丁字节和数值布局。
